# 🏰 JavaFX Tower Defense Game

A strategic Tower Defense game built with **JavaFX**, focusing on Clean Code and Object-Oriented Programming (OOP) principles. Developed as a 2nd-year Computer Engineering student project.


## 🚀 Features
* **Dynamic Level Loading:** Maps and waves are parsed from external `.txt` files.
* **OOP Focused:** Utilizes inheritance, polymorphism, and factory patterns (e.g., `Tower` and `Bullet` hierarchies).
* **Interactive UI:** Drag-and-drop tower placement and real-time currency management.
* **Visual Effects:** Animations for cell generation and death particle effects.

## 🛠️ Technologies Used
* **Language:** Java 21
* **Framework:** JavaFX
* **Build/IDE:** Eclipse

## 📁 Project Structure
* `src/`: Contains all logic for game mechanics, UI, and asset loading.
* `src/*.png`: Game assets including towers, enemies, and backgrounds.
* `level*.txt`: Configuration files for map layouts and enemy wave data.

## 🎮 How to Run
1.  Ensure you have **Java 21** or later installed.
2.  Download the project folder.
3.  Run the `Baslat.bat` file (for Windows users) which handles the JavaFX module-path and dependencies automatically.
